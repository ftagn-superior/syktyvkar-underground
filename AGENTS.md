# Работа с игровыми коллекциями

- Для анимаций сначала прочитайте [Добавить анимацию](docs/add-animation.md). Используйте `pnpm animations:add`, затем `pnpm animations:sync` и `pnpm animations:check`; выполните проверки скинов и локального предпросмотра из инструкции. Источник метаданных — `content/animations/catalog.json`, клипы — `apps/client/src/rendering/avatars/clips/`. Карты `catalogVersions` клиента и сервера содержат `reactions` и `animations`; сохраняйте оба ключа.
- Для реакций сначала прочитайте [Добавление реакции](docs/reactions.md). Канонический путь: `pnpm reactions:add`, затем `pnpm reactions:check` и `pnpm test:reactions`. Инструкция содержит полный пример, правила SVG, проверку двух клиентов и выпуск.
- Общие соглашения S-29 и порядок интеграции PR: [Коллекции](docs/collections.md). Сохраняйте стабильные ID и независимость контрактов от движка. Обычный стикер не требует нового серверного обработчика или миграции БД.
- Источник истины реакций — `packages/contracts/src/reactions.ts`, авторские SVG — `apps/client/public/reactions/`. Не редактируйте `dist/` и не вычисляйте версию каталога вручную.
- Для браузерных/сетевых проверок используйте только тестовый `SU_TEST_DATABASE_URL`; `pnpm build` выполняется до браузерного сценария. Отмечайте пропущенные SQL-тесты и непроверенные устройства.
- Новые игровые элементы не добавляйте как побочный результат изменения инструментария. Демонстрационные добавления проверяйте во временной копии/фикстуре.

- Каркас `humanoid-v2`: локти, колени и визуальный корень описаны в `docs/animation-rig-v2.md` и `docs/add-animation.md`. Для поз на земле обязательны `support: ground`, полная маска `articulatedBody`, явный вариант/отказ для коляски и именованный статичный reduced motion. Не уменьшайте физическую капсулу и не добавляйте root motion. Отказ сервера из-за места/опоры не обходить.
- Проверочные сидение/лежание/бок/колесо лежат в `tests/fixtures/animation-rig/`, не в игровом каталоге. `pnpm test:animation-rig:browser` создаёт отдельную копию исходников, регистрирует фикстуры генератором и пересобирает клиент/сервер; сначала выполните `pnpm build`.
- После изменений каркаса/скинов/аниматора выполните форматирование, `animations:sync`, оба валидатора, профильные тесты и `pnpm check`. Отпечаток v2 включает их исходники; новый файл с семантикой показа включайте в `animationContractFiles`. Сохраняйте `reactions` и `animations` в обеих картах совместимости.
