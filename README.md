# Syktyvkar Underground

Проект браузерной многопользовательской игры на изометрической 3D-карте Сыктывкара. Игроки управляют персонажами в общем мире, взаимодействуют с объектами и в дальнейшем участвуют в разных игровых режимах. Цель развития — до 50 игроков одновременно; первая технодемо проверяется на 8 клиентах.

Основа текущего этапа — **Babylon.js + Havok + Colyseus, TypeScript и Vite**. Первая технодемо v0.1 — простая площадка, движение персонажей, столкновения и один общий ящик. Прыжки, платформа, транспорт и городская карта отложены.

В репозитории сохранены исследования, автономный прототип карты и проект архитектуры. Игровой клиент и сервер ещё предстоит реализовать. Начать знакомство стоит с [контекста проекта](PROJECT_CONTEXT.md), затем прочитать [архитектуру](docs/architecture.md) и [спецификацию v0.1](docs/mvp-network-playground.md). Для передачи разработчикам использовать также [план задач и проверок](docs/mvp-delivery-plan.md).
