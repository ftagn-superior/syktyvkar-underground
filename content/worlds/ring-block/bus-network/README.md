# Автобусная сеть ring-block

Остановки, маршруты и путь автобусов по улицам в пределах мира — основа для быстрых
поездок и карты автобусов. Получены разово; `pnpm world:build` эти данные не читает.
Игра подключает `network.json` через `@su/contracts` (`busNetworkFor`) на клиенте и сервере,
`map.json` — подложку карты — клиент грузит отдельным чанком. В игре видны только маршруты
`BUS_ROUTES_IN_GAME` (сейчас 1, 4, 8, 17М, 18М, 19, 20, 54М, 101, 174).

| Что                         | Источник                                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------------------- |
| Какие маршруты и их порядок | [Транспорт 11](https://transport11.ru/timetable/syktyvkar), страницы маршрутов + `overrides.json` |
| Координаты остановок        | OpenStreetMap: `highway=bus_stop`, `public_transport=platform`, `route=bus`                       |
| Путь между остановками      | OpenStreetMap: автомобильные дороги, кратчайший путь с учётом одностороннего                      |

С «Транспорт 11» берутся только основные страницы маршрутов, не чаще одной в 2 с:
обратное направление (`?direction=1`) и карта (`/map`) закрыты в robots.txt. Лицензия
сайта не указана; перед публичным выпуском стоит запросить разрешение (admin@route51.ru).
Данные OSM © участники OpenStreetMap, лицензия [ODbL 1.0](https://opendatacommons.org/licenses/odbl/).
Снимки, SHA-256 и счётчики — в `provenance.json`.

## Пересчёт

```sh
pnpm world:bus:network -- --fetch       # новые снимки → output/bus-network/ (≈3 мин)
pnpm world:bus:network -- --fetch-osm   # только снимок OSM (улицы, дома, остановки)
pnpm world:bus:network                  # пересчитать network.json и map.json из снимков
```

## Формат `map.json` (formatVersion 1)

Подложка карты: `roads[]` — проезжие улицы `{ k: класс, p: ломаная X/Z }` до 300 м за краем
мира, `buildings[]` — контуры домов в границах мира. Упрощены до 0,7–0,8 м.

## Формат `network.json` (formatVersion 3)

- `stops[]` — `id`, `name` (как у «Транспорт 11»), `position` (X/Z, м),
  `platforms[]` (`id`, `position`, `sideHint`, `bearing`, `source`), `routes`.
- `routes[]` — `ref`, `name`, `transport11` (ссылка), `directions[]`:
  - `headsign` — конечная данного направления;
  - `circular` — кольцевой маршрут (`true`/`false`);
  - `sequence` — `{ stopId, platformId }` остановок мира и `{ offWorld: [имена] }`;
  - `legs[i]` — путь по улицам между i-й и (i+1)-й остановкой мира в `sequence`: куски
    ломаной в пределах мира + 300 м с учётом стороны дороги (RHT). Вершины не
    упрощаются, поэтому на общих улицах у разных маршрутов они совпадают.

Правило быстрой поездки: поездка начинается с конкретной платформы `fromPlatformId`.
На обычном направлении можно ехать только вперёд по `directions[].sequence`; на
кольцевом — по ходу кольца с подсказкой `fasterOpposite`, если обратное направление
короче.

Сопоставление имён и ручные уточнения — в `overrides.json` и таблице `ALIASES` в
`tools/world-build/src/bus-network.ts`. Платформы одного имени объединяются в одну
остановку (если не разнесены, как две «Школы №35»), но для посадки и высадки каждая
платформа хранится отдельно.

## Павильоны на остановках

Павильоны — обычные статичные экземпляры (`bus-stop-<id остановки>-<№ платформы>`, модели
«Остановочный павильон», варианты 01, 03, 04, 06, 07, 08), поэтому ставятся патчем
расстановки на остановленном мире, как любая правка карты:

```sh
make build                                   # выпуск того же каталога, что на сервере
# остановить сервер
make map-export FILE=output/map-base.json
pnpm world:bus:stops -- --base output/map-base.json --edited output/map-bus-stops.json
make map-patch BASE=output/map-base.json EDITED=output/map-bus-stops.json PATCH=output/map-bus-stops.patch.json
make map-check PATCH=output/map-bus-stops.patch.json
make map-apply PATCH=output/map-bus-stops.patch.json
make start
```

`world:bus:stops` ставит павильон к каждой платформе без модели остановки в радиусе 6 м:
спиной от дороги, со сдвигом не дальше 4 м от точки платформы (подсказка срабатывает
внутри), не задевая дорог, проездов, парковок и коллайдеров, с высотой Y по тому же
правилу фундамента, что размещение из игры. Не ставятся платформы за границей мира и
интерполированные остановки — их точка угадана на оси улицы. Повторный запуск на свежем
экспорте ничего не добавляет. Seed новых установок команда не меняет.

## Проверить вручную (снимок 15.11.2026)

- «Центральный универмаг» нет в OSM; по маршрутам 6/20/46, 9 и 101 он
  ставится примерно, в разных местах; «Городской суд» (1М) — тоже. Сверить с 2ГИС/Яндекс.Картами и добавить
  точки в OSM или алиасы.
- Платформы «Беличий парк» (−500,1; 863,6) и «Школа №36» (−676,1; 853,6) лежат за южной
  границей мира (z ≤ 850): подсказка там недоступна, павильонов нет, вторые платформы
  этих остановок в мире.
- Обратный путь `twoWay`-маршрутов нарисован тем же путём; на односторонних улицах
  автобус фактически едет иначе.
- Пригородные маршруты (103, 125–127) попадают в мир двумя-тремя остановками;
  междугородние (5xx) исключены.
