# Документация

Художественное направление следующей переработки ассетов: [визуальный стиль и главный референс](art-style-guide.md). Гайд описывает целевой вид; готовность реализации проверяется отдельно в игре.

Текущая версия находится в production, все приёмки завершены — подтверждение владельца проекта от 12 ноября 2026 года. Этот каталог описывает реализованное поведение; исторические замеры и исследования отделены от рабочих инструкций.
