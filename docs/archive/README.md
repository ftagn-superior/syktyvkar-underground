# Архив исследований, заданий и выполненных планов

Здесь сохранены исходные исследования, задания и планы уже реализованных этапов. Это исторические материалы: предложения, ссылки, версии, права доступа и оценки в них относятся к своим датам и не заменяют текущие инструкции. Не повторяйте старые миграции и задания только потому, что в архиве сохранены императивы или незакрытые пункты исходного плана.

- [Первое исследование](pre-pre-search.md) — Brno2000, izomapa и происхождение автономной карты.
- [Исследование игровой архитектуры](pre-search.md) — сравнение движков, физики и сетевой модели.
