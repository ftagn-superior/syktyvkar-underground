# Переработка интерфейса: спецификация

Образец — [`mock.html`](mock.html). Значения ниже взяты из него. Размеры в `em` считаются от базового кегля HUD: около 15px на экране 1440px, не меньше 11px на узких.

## 1. Основа стиля

- **Материал:** печатная бумага. Панель непрозрачная, с рамкой 2px и жёсткой тенью строго вниз, без размытия. Единственное полупрозрачное место — подложки строк чата и подписей над головами.
- **Орнамент:** лента из ромбов с точкой в центре (мотив коми вязания) высотой 10px, брусничного цвета. Идёт по верхнему краю всплывающих окон и карточки-пропуска. В лобби тот же узор крупно и бледно лежит на небе.
- **Знак бренда:** упрощённый памятник «Трудовая слава» (модель в `content/buildings/ring-block/manual/trudovaya-slava/`): постамент, два пилона, плита с тёмным круглым медальоном, шесть пластин разной высоты веером. SVG 24×24 есть в `mock.html`, блок `.brand`.
- **Красный — только для главного.** Одна главная кнопка на экране («Войти в мир», «Поставить»), клавиша в подсказке действия, счётчик рюкзака, орнамент.

## 2. Токены

Тема задаётся атрибутом на корне. Компоненты читают только токены.

| Токен | День («берёста») | Ночь («полночь») | Назначение |
| --- | --- | --- | --- |
| `--p` | `#F3EAD8` | `#18213F` | Фон панели |
| `--p2` | `#E7DCC6` | `#232D52` | Фон кнопки, поля ввода, вставки |
| `--ink` | `#1F2420` | `#F1ECDF` | Текст, иконки |
| `--mut` | `#6A685C` | `#A3ABC6` | Вторичный текст |
| `--ln` | `#2B2F2A` | `#5D6A99` | Рамки. Ночью приглушённо-синяя, не белая |
| `--hard` | `#8A8170` | `#0A0E1F` | Жёсткая тень |
| `--pri` | `#C8342F` | `#C8342F` | Главное действие, орнамент |
| `--pri-ink` | `#FFF4E6` | `#FFF4E6` | Текст на красном |
| `--amber` | `#E8A33A` | `#E8A33A` | Кольцо фокуса, выделение |
| `--me` | цвет игрока | цвет игрока | Только элементы «про игрока» |

Дополнительные цвета палитры для состояний: «Тайга» `#2F7D55` (успех), «Вычегда» `#2E6FA8` (справка, ссылки). Предупреждение — `--amber`.

Смена темы мгновенная: на цветовые свойства переходы не ставятся.

### Правило темы

- Высота солнца `h` = `sunPosition(hour).y` (от −1 до 1, 0 на горизонте).
- Авто: день при `h > 0`, ночь иначе, с гистерезисом около ±0,02, чтобы тема не мигала у горизонта.
- Настройка «День» или «Ночь» отменяет авто. Свет в мире от настройки не зависит.

## 3. Шрифты

| Роль | Гарнитура | Начертания |
| --- | --- | --- |
| Заголовки окон, главная кнопка, словесный знак, `?` | Rubik | 800 (700 как запасное) |
| Всё остальное | Golos Text | 400, 500, 600, 700 |

- Базовое начертание интерфейса 600; длинный текст, строки чата, подписи над головами — 500.
- Подписи клавиш набираются Golos Text 700, без моноширинного шрифта.
- Обе гарнитуры содержат буквы коми Ӧ и І. При замене гарнитуры это обязательное требование.
- Числа, которые меняются на месте (часы, счётчики), — `font-variant-numeric: tabular-nums`.

## 4. Примитивы

**Панель.** Фон `--p`, рамка 2px `--ln`, радиус 0,9em, тень `0 0.24em 0 --hard`.

**Кнопка.** Фон `--p2`, рамка 2px `--ln`, радиус 0,75em, тень `0 0.2em 0 --hard`.

- Наведение: подъём на 0,08em.
- Нажатие: сдвиг вниз на 0,16em, масштаб 0,95, тень сжимается до 0,04em.
- Выбрана или раскрыта (`aria-pressed`, `aria-expanded`): фон `--ink`, текст `--p`, радиус 1,35em. Это «сквиркл», не круг.
- Переходы `transform` и `border-radius` идут по пружинной кривой `cubic-bezier(.3, 1.55, .5, 1)`, 0,28–0,4 с.
- Фокус: кольцо 3px `--amber` с отступом 2px.
- Главная кнопка: фон `--pri`, текст `--pri-ink`.

**Иконка в кнопке.** 1,25em, линия 2,2 при поле 24. Кнопка заметно больше иконки: 3em в строке чата, 3,4em у `?`, 3,8em в доке.

**Подпись клавиши.** 0,6em, 700, непрозрачность 0,42, в правом нижнем углу с отступами 0,65em и 0,45em. На узких экранах и в режиме касаний скрыта.

**Чип.** Панель с отступами 0,55em × 0,95em, иконка 1,15em и текст.

**Всплывающее окно.** Панель с лентой орнамента сверху и заголовком Rubik. Появляется за 0,32 с по пружинной кривой из точки привязки. Отступы 0,9em.

**Счётчик-значок.** Красная «таблетка» высотой 2em, минимальная ширина 2em, поля 0,5em, рамка 2px; выступает за левый верхний угол кнопки на 0,6em.

**Знак игрока.** Девять фигур в поле 24×24: круг, скруглённый квадрат, треугольник, ромб, пятиугольник, шестиугольник, восьмиконечная звезда, клевер из четырёх кругов, арка. Заливка цветом игрока, тонкий контур цвета `--ln`, чтобы светлые цвета читались на бумаге. Размер 1,1em в тексте, 2em в лобби.

## 5. HUD в мире

```
┌──────────────────────────────────────────────────────────┐
│ [?]                 (уведомление)        [☀ 14:30] [👥 3] │
│                     (размещение)                [список] │
│                                                          │
│                      ◆ Вы                                │
│                       🧍      [Z Подобрать · ящик]       │
│                                                          │
│ лента чата                                               │
│ [окно реакций/анимаций]                         [лоток]  │
│ [T][R][F]                                       [V][X ²⁴]│
└──────────────────────────────────────────────────────────┘
```

Чат на схеме свёрнут. В раскрытом виде нижний левый ряд выглядит так: `[T][ поле ввода      ][R][F]`.

Отступ от краёв экрана 1,2em (0,7em на узких, плюс безопасные зоны устройства).

### Верх

- **`?`** — кнопка без цвета. Открывает панель управления и настроек.
- **Часы** — чип: иконка солнца при `h > 0`, иначе луны; время мира `ЧЧ:ММ`.
- **Игроки** — чип-кнопка: иконка людей и число. По щелчку под ним окно шириной 14em: заголовок «В сети», «N из 8», строки «знак · имя», у своей строки пометка «вы».
- **Уведомление** — «таблетка» по центру сверху, до половины ширины экрана, держится около 2,4 с. Подсказка размещения занимает то же место.

### Чат (внизу слева)

- Ширина `min(25em, 58%)`.
- **Лента:** до пяти последних строк над полем ввода. Строка: знак игрока, имя полужирным, текст. Подложка — цвет панели с непрозрачностью 84%, радиус 0,5em. Четвёртая с конца строка бледнеет до 0,55, пятая до 0,3. Системные строки курсивом цвета `--mut`.
- **Свёрнут (по умолчанию):** поля ввода нет. Под лентой ряд из трёх кнопок 3em: чат `T`, реакции `R`, анимации `F`. Лента сообщений видна и в свёрнутом виде.
- **Раскрыт:** на месте ряда панель с полем («Enter — отправить») и кнопками реакций и анимаций. Кнопка чата остаётся в панели в состоянии «выбрана» и служит кнопкой закрытия.
- **Раскрытие:** `T` или кнопка чата раскрывает поле и ставит в него фокус. Поле остаётся раскрытым после отправки сообщения, фокус остаётся в нём.
- **Сворачивание:** `Esc`, щелчок по миру или кнопка чата сворачивают поле обратно в кнопку и возвращают фокус в мир. Пока фокус в поле, `T` — обычная буква и чат не закрывает.
- Несохранённый текст при сворачивании не теряется: при следующем раскрытии он на месте.
- Состояние «раскрыт / свёрнут» живёт в пределах сессии; между перезагрузками не хранится (при входе чат свёрнут).
- От первого лица раскрытие поля, как и сейчас, освобождает курсор.
- В `mock.html` поле ввода показано постоянно; это отличие от спецификации, верна спецификация.

### Реакции и анимации

Окно открывается над рядом кнопок (или над строкой ввода, если чат раскрыт), шириной с блок чата. Открытие окна не меняет состояние чата.

- Заголовок и счётчик «показано из всего».
- **Фильтры:** «Все» и категории из каталога. Горизонтальная лента маленьких кнопок; если не помещается, прокручивается вбок.
- **Список:** область высотой 9,6em с вертикальной прокруткой и тонкой полосой.
  - Реакции: сетка в 4 колонки (3 на узких). Плитка — стикер 2,1em и подпись 0,66em. При фильтре «Все» сверху строка «Недавние» из четырёх последних.
  - Анимации: кнопки с названием в 2 колонки (1 на узких).
- Выбор закрывает окно. Реакция показывает стикер над персонажем, анимация запускается как сейчас.
- Состояния ожидания и перезарядки из текущей реализации сохраняются: недоступные плитки приглушены, причина показана строкой состояния в окне.

### Док (внизу справа)

- Кнопки 3,8em: вид от первого лица `V`, рюкзак `X`.
- На рюкзаке счётчик-значок с общим числом предметов. При пустом рюкзаке значок скрыт.

### Рюкзак

- Лоток шириной 20em над доком: заголовок «Рюкзак», «N шт.», сетка 4 колонки.
- Плитка: иконка 58% ширины, количество в правом нижнем углу, номер клавиши в левом верхнем (бледный).
- Щелчок по плитке или клавиша с номером закрывает лоток и включает размещение.
- Пустой рюкзак: «Пусто. Подойдите к предмету и нажмите Z.»
- Гость: «Войдите через Telegram, чтобы носить вещи».
- От первого лица рюкзак, как и сейчас, недоступен.

### Размещение

- Наверху по центру плашка: иконка, название, «щёлкните по миру», «Esc — отмена».
- Клавиши поворота (`W S`, `A D`, `Q E`, шаг 15°) остаются; их подсказка живёт в панели управления и не занимает экран.
- Состояния из текущей реализации («подойдите ближе», «выберите свободную поверхность», «сохраняем…») показываются в той же плашке.

### Подсказка действия

- Плашка над предметом: красная клавиша 2,2em с буквой, действие полужирным, название предмета мелко цветом `--mut`.
- Появляется по пружинной кривой, привязана к предмету в экранных координатах.
- Щелчок или касание по плашке выполняет действие.
- Логика выбора ближайшего объекта, задержки и приоритеты (`interaction/prompt.ts`) не меняются.

### Над головой

- **Подпись:** «таблетка» высотой 24px, фон `--p` с непрозрачностью 0,72, без рамки. Внутри знак игрока 16px и имя, 13px, начертание 500. Своя подпись показывает «Вы».
- **Пузырь чата:** панель с рамкой, текст 500.
- **Стикер реакции:** без подложки, 60px.
- **Подписи мест:** та же «таблетка», что у игроков, без знака.

## 6. Лобби

Сетка: шапка; ниже слева персонаж, справа карточка; внизу полоса персонажей. На узких экранах всё в одну колонку.

- **Фон:** живой мир, как сейчас, без затемняющей заливки поверх. Если мир ещё не загружен — небо и земля ровным цветом и крупный бледный орнамент.
- **Шапка:** слева панель со значком «Трудовой славы» и словесным знаком (Rubik, вторая строка разрядкой). Справа чип «N из 8 · мир доступен».
- **Персонаж:** живой предпросмотр на постаменте в цветах панели. Под ним стрелки и табличка с именем и названием модели.
- **Карточка-пропуск:** лента орнамента; строка «Пропуск · Полигон 01»; заголовок «Видза оланныд!» (приветствие на коми, Rubik); подзаголовок; поле имени; выбор цвета; строка «Ваш знак»; главная кнопка «Войти в мир» без иконки.
  - Вход через Telegram, повтор загрузки, выход из аккаунта и переключатель звука остаются в карточке второстепенными кнопками и ссылками.
- **Выбор цвета:** круглые образцы 2,4em. Выбранный становится «сквирклом» с двойным кольцом. Последний образец «свой цвет» открывает блок с пунктирной рамкой и двумя ползунками: оттенок 0–359 и тон. Тон ограничен светлотой 38–74% при насыщенности 68%, чтобы любой выбор читался и на газоне, и на бумаге. Название цвета показывается справа от подписи поля.
- **Персонажи:** доступные — кнопки с миниатюрой, названием и состоянием. Закрытые — одна пунктирная плашка «Ещё N персонажей появятся с обновлениями».

## 7. Панель управления и прочее

Макет не перерисовывает эти окна; они переводятся на новые примитивы без изменения содержания.

- **Панель управления (`?`):** список клавиш, звук (три ползунка), качество графики, тема интерфейса (Авто / День / Ночь), диагностика, «На старт», «Выйти».
- **Диагностика, восстановление графики, пауза хранилища, загрузка области, панель от первого лица, стик для касаний:** панель, кнопки и чипы из раздела 4.

## 8. Движение и доступность

- Пружинные переходы только на `transform`, `border-radius`, `opacity`.
- При `prefers-reduced-motion: reduce` переходы и появления отключаются.
- Контраст текста к панели в обеих темах не ниже 4,5:1; токены из раздела 2 этому удовлетворяют.
- В режиме касаний цели не меньше 44px.
- Режим `forced-colors`: панели получают системные цвета, как сейчас делает `.su-facet`.
