# Фото фасадов из Street View: инструкция для ИИ-агентов

Когда пользоваться: перед созданием или правкой рецепта здания `content/buildings/ring-block/osm-way-*/source.json` — цвета, этажность, крыльцо, вывески, балконы, `details`. Опирайтесь на реальный вид здания, а не на догадки.

Инструмент: `pnpm reference:streetview` (`tools/streetview-capture.ts`). Краткое описание для людей — в [моделях зданий](building-assets.md#фото-фасадов-из-street-view).

## 1. Проверьте, что уже скачано

- Кадры лежат в `reference/streetview/<osm-id>/`: `manifest.json`, `<фасад>.jpg`. Папка `reference/` локальная и в Git не попадает; в свежем клоне её нет.
- Если `manifest.json` нужного здания уже есть, ничего не скачивайте и переходите к шагу 3.
- Остальные подпапки `reference/` — ручные снимки пользователя (см. `reference/README.md`). Их тоже стоит посмотреть.

## 2. Скачивание расходует квоту пользователя

- Нужен ключ `GOOGLE_MAPS_KEY` в `.env`. Никогда не выводите, не логируйте и не коммитьте ключ, не подставляйте его в команды и не печатайте `.env`. Если ключа нет, попросите пользователя, обходных путей не ищите.
- Сначала всегда запускайте `--dry-run`: metadata-запросы бесплатны, а план покажет число кадров к скачиванию.
- Скачивайте только нужные здания через `--building <osm-id>`. `--all` и `--match` — только по явной просьбе. Предохранитель `--max-images` (по умолчанию 150) без согласия пользователя не поднимайте.
- Не открывайте сайт Google Maps в браузере для автоматической съёмки и не скрапьте его. Работайте только через этот скрипт: он использует официальный API.
- Повторный запуск докачивает только новые или перенаведённые кадры; `--force` без причины не используйте.

```sh
pnpm reference:streetview --building osm-way-1258973447 --dry-run
pnpm reference:streetview --building osm-way-1258973447
```

## 3. Смотрите размеченные кадры

```sh
pnpm reference:streetview --building osm-way-1258973447 --mark
```

Команда работает без сети и ключа: она рисует разметку поверх уже скачанных кадров в `reference/streetview/<osm-id>/marked/<фасад>.jpg`. Читайте эти файлы как изображения. Сверху у каждого кадра подпись: здание, ID, фасад, сторона света и дата съёмки.

| Разметка               | Значение                                                                   |
| ---------------------- | -------------------------------------------------------------------------- |
| красная заливка        | стена, ради которой сделан кадр                                            |
| оранжевый пунктир      | другие стены этого же здания; у части длинного фасада — весь фасад целиком |
| синий контур и подпись | соседние здания (подпись — `name` из их `asset.json`)                      |

Если разметка мешает рассмотреть деталь, откройте сырой кадр `reference/streetview/<osm-id>/<фасад>.jpg`. Людям удобнее страница `reference/streetview/index.html` с мини-картой точки съёмки.

## 4. manifest.json

Координаты — мировые метры ring-block, как в `content/worlds/ring-block/cells/*.json`: x — восток, z — юг, север — −Z. Контур рецепта равен мировому контуру минус `position` здания в ячейке.

| Поле                                    | Смысл                                                                                                                                           |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `facades[].key`                         | Сторона внешней нормали (`N`, `NE` … `NW`). При повторе стороны добавляется номер (`SW2`), часть длинного фасада — через точку (`NE.1`, `NE.2`) |
| `facades[].side`                        | Та же сторона без номера. Совпадает со сторонами `details` рецепта (отклонение до 40°)                                                          |
| `facades[].points`, `length`, `height`  | Концы стены, её длина и реальная высота в метрах (без игрового `heightScale`)                                                                   |
| `facades[].part`                        | `[номер, всего]` для частей длинного фасада                                                                                                     |
| `views[].facade`                        | Ключ фасада, который снимали                                                                                                                    |
| `views[].pano`, `distance`, `incidence` | Позиция камеры, расстояние до середины стены и угол к её нормали (0° — съёмка в лоб, больше 60° — сильный ракурс)                               |
| `views[].visibility`                    | Доля точек стены, не закрытых другими зданиями. Деревья не учитываются                                                                          |
| `views[].date`, `panoId`                | Месяц съёмки панорамы и её ID                                                                                                                   |
| `views[].shots[]`                       | Файл, `heading`, `pitch`, `fov` и `overlays` — проекции контуров в пикселях кадра 640×640                                                       |
| `missing`                               | Фасады без пригодной панорамы — обычно стены во дворах                                                                                          |

## 5. Ограничения: не делайте выводов сверх кадра

- Панорамы в основном 2021 года. Вывески, цвета и пристройки могли измениться; дата есть в подписи и в `views[].date`.
- Деревья не моделируются, и летняя листва часто закрывает стену. Высокий `visibility` не гарантирует, что стену видно.
- Разметка — проекция контура с камеры на высоте 2,5 м над ровной землёй. Сдвиг на несколько процентов кадра нормален, на склонах и у близких камер он больше. Если контур явно лёг на другое здание, верьте фото, а не разметке, и сообщите об этом пользователю.
- Кадр 640×640: мелкие детали неразличимы. Для детали дайте пользователю ссылку на панораму: `https://www.google.com/maps/@?api=1&map_action=pano&pano=<panoId>&heading=<heading>&pitch=<pitch>&fov=<fov>`.
- Не описывайте то, чего не видно. Для стен без кадра (`missing`) или закрытых листвой действует общее правило из [`content/buildings/AGENTS.md`](../content/buildings/AGENTS.md): описывайте видимую геометрию, назначение и адрес не угадывайте.
- Кадры не коммитьте и никуда не выгружайте: это материалы Google для локальной работы.

## 6. Перенос в рецепт

- Цвет стены оценивайте по участку без прямого солнца и бликов: Street View часто пересвечен. Держитесь палитры из [руководства по стилю](art-style-guide.md).
- Этажность считайте по рядам окон на кадре в лоб (`incidence` меньше 30°), а не на ракурсном.
- Сторону крыльца, вывески или балкона берите из `facades[].side` кадра, где деталь видна, и записывайте в `details` той же стороной.
- После правки рецепта выполните проверки из [моделей зданий](building-assets.md) и `pnpm world:catalog:check --sources`.
