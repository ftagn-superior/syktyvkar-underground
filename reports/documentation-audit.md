# Аудит документации

12 ноября 2026 года. Аудит выполнен по исходникам текущей рабочей копии, конфигурации пакетов, содержимому миров и существующим отчётам. Владелец проекта подтвердил: **текущая версия работает в production, все приёмки пройдены**. Этот статус включён в рабочую документацию; старые измерения сохранены как история конкретных прогонов.

## Исправления

| Расхождение | Актуальное описание и основание |
| --- | --- |
| Архитектура описывала предполагаемые каталоги и ранний MVP | Реальные компоненты `apps/`, `packages/`, `tools/`, их границы и потоки данных |
| Гостевой запуск якобы допускался без БД | `readDatabaseUrl` требует PostgreSQL всегда; только параметры Telegram необязательны полным набором |
| Единственный ящик и сброс мира при перезапуске | Постоянные экземпляры, инвентари, очередь записей и восстановление в `items/store.ts` / `runtime.ts` |
| Город целиком в одной ячейке, импорт OSM отложен | Исходная ячейка преобразуется сборщиком в 40 runtime-ячеек; работает импортёр прототипа и снимка OSM |
| Старые версии и видимость всех участников | Протокол 9, мир 4, ячейка 2, PostgreSQL 3; `StateView` использует AOI 500/800 м |
| Жесты и танец описывались как следующий этап | Каталог, клипы, серверное состояние и интерфейс уже реализованы |
| Открытые пункты старых отчётов выглядели текущими блокерами | Отчёты помечены историческими; актуальный статус приёмки и production вынесен в начало |
| README смешивал управление, серверное обслуживание и приёмку | Отдельные [эксплуатация](../docs/operations.md), [проверки](../docs/testing.md) и [указатель](../docs/README.md) |

## Удалённые и сохранённые материалы

Удалены выполненные/заменённые документы: `docs/mvp-delivery-plan.md`, `docs/mvp-network-playground.md`, `docs/large-map-delivery-plan.md`, `docs/dynamic-map-integration-scope.md`. Реализованные правила перенесены в рабочие описания; команды регрессий и бюджеты измерений сохранены в `docs/testing.md`. Прежние тексты доступны в истории Git.

`pre-pre-search.md` и `pre-search.md` перенесены без изменения содержимого в [архив исследований](../docs/archive/README.md). Автономный HTML-прототип сохранён по прежнему пути, поскольку используется импортёром. Отчёты измерений сохранены; ссылки на локальные неотслеживаемые снимки заменены указанием путей артефактов.

Учтены обновления геометрии кольца и инструмент `world:preview-ring` из основной ветки. Сохранены ещё не реализованные расширения карты; описание предпросмотра уточняет, что запуск без `--no-import` также обновляет генерируемый контент.

## Проверка результата

Проверены локальные Markdown-ссылки и якоря рабочих документов/отчётов, наличие упомянутых pnpm-команд в `package.json`, синтаксис shell-примеров и корректность JSON-примеров. Версии, частоты, радиусы, лимиты, каталоги и параметры трёх миров сопоставлены с кодом и JSON-данными. Содержимое перенесённых исследований сверено с исходными Git-объектами. `git diff --check` прошёл без пробельных ошибок. Итог автоматической проверки: 27 документов, 158 локальных ссылок и якорей, 48 команд pnpm, 30 примеров JSON/shell — ошибок нет. Оба архивных исследования побайтово совпадают с исходниками в Git; изменения затрагивают только Markdown.

Исходные исследовательские переписки не проверялись на актуальность внешних ссылок: они сохранены как архив. Удалённый production-сервер и его конфигурация в этом аудите не менялись и повторно не обследовались. Статус production/приёмки получен от владельца, а не из нового нагрузочного прогона.

Изменена только документация. В рабочей копии отсутствует `node_modules`; сборка, браузерные и серверные тесты в этом аудите не запускались. Для документационных изменений использованы проверки ссылок, примеров и соответствия исходникам.
