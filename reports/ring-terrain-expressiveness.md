# Выразительный рельеф ring-block — S-45

15 ноября 2026 года. Подготовлена первая игровая итерация для PR в main и последующей
приёмки владельцем в production. Ветка включает актуальный main `a4d5d54` с
каталогами реакций/анимаций и новыми командами. Production-приложение и его БД
в этой работе не изменялись.

## Результат

На прежнюю сглаженную поверхность добавлены три широкие формы: спад к Сысоле,
подъём по Димитрова и горка у Оплеснина / бани №4. Связная городская площадка
под длинными домами и ограждениями поднята целиком с сохранением прежних локальных
уклонов и плавным переходом к окружению. Мелкий исходный рельеф не возвращался.

| Контрольный профиль                          |     Длина | Исходная поверхность | Новая поверхность |
| -------------------------------------------- | --------: | -------------------: | ----------------: |
| Спуск к Сысоле, X −500…1950, Z −200          |    2450 м |      21,825 м спуска |   37,113 м спуска |
| Димитрова от католического храма к Морозова  | 846,005 м |      3,859 м подъёма |  10,358 м подъёма |
| Оплеснина / баня №4, полный перепад маршрута | 929,190 м |              6,169 м |          11,956 м |

Это одинаковые маршруты на исходной и целевой сетках; они могут отличаться от
контрольных отрезков исторического обсуждения. Координаты и отсчёты профилей
записывает проверочный инструмент. Шаг сетки остаётся **20 м**, число узлов —
**15 399**, границы X −1500…2000 / Z −850…850 м. Максимальный уклон сетки
**5,561°** сохранился; p95 изменился с 1,819° до 3,079°.

Из 5676 исходных редактируемых экземпляров изменена Y у 5376. Модели, ID,
X/Z, повороты и остальные поля сохранены; здания не наклоняются вместе со склоном.
Обычные фундаменты и опорные точки используют прежние явные правила. Сохранены
78 подходов с прежними длинами; 38 ранее удалённых исторических подходов не нужны:
максимальный проверенный порог у них 0,175069 м при лимите 0,18 м.

Для 1829 зданий расширения с цоколем внутри модели добавлена миграционная политика
`embedded-footprint`: сначала сохраняется высота крыши относительно максимума
земли под точным контуром, затем при необходимости модель опускается для сохранения
заглубления не менее `min(исходное заглубление, 0,3 м)`. Таких ограничений потребовали
226 экземпляров. Минимальное заглубление — 0,30 м, минимальное превышение крыши
над землёй — 1,246 м. Изменённая модель, открытое основание или погребённая крыша
блокируют перенос. Дополнительные фундаменты этим моделям не создаются;
размещение их из игрового каталога не разрешается.

Границы построены по полному действующему canvas: 652 сегмента на внешнем
периметре. Регрессия отдельно проверяет случай, когда исходные шаблоны описывают
ещё старый малый участок.

## Применение после мерджа

Нужны согласованные клиент и сервер текущего main, мир v6 и БД v8. Новая схема БД
для S-45 не добавляется. Обычный `make run` не заменяет перенос высот.

1. Остановить сервер и дождаться финального сохранения. Сохранить действующий
   исходный каталог `dist/worlds/ring-block` вместе с `authoring.json` и всей
   `private/` в `output/s45-release/source-world` **до новой сборки**. Это вход
   мигратора; он должен совпадать с фактическим asset release БД.
2. Собрать новый commit через `pnpm build`. Проверить ожидаемый новый asset release.
3. Подготовить правила и штатный план по актуальному сохранённому состоянию:

```sh
node --import tsx tools/prepare-terrain-pose-rules.ts \
  --source output/s45-release/source-world \
  --target dist/worlds/ring-block \
  --output output/s45-release/terrain-pose-rules.json --ring-embedded

node dist/server/terrain-command.mjs plan \
  --source output/s45-release/source-world \
  --target dist/worlds/ring-block \
  --rules output/s45-release/terrain-pose-rules.json \
  --report output/s45-release/plan.json
```

4. Для `status: valid` и пустого `issues` применить именно этот план:

```sh
node dist/server/terrain-command.mjs apply \
  --source output/s45-release/source-world \
  --target dist/worlds/ring-block \
  --rules output/s45-release/terrain-pose-rules.json \
  --plan output/s45-release/plan.json \
  --report output/s45-release/applied.json

make start
```

При изменившихся позах, неоднозначной опоре или новых пересечениях план отклоняется;
правила не разрешают обойти проверки. Рабочий `plan/apply` в этой работе не запускался.
После запуска владелец оценивает три маршрута в production обычной камерой и от
первого лица; по впечатлениям подготавливается следующая итерация PR.
