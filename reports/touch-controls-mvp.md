# Сенсорное управление: ограниченный MVP

12 ноября 2026 года. Основа: `487f5d0` и изменения рабочей ветки. Объём — [согласованный план](../docs/plans/touch-controls-mvp.md). Реализация клиентская; сервер, протокол, форматы мира и БД не изменены. Публикация игры не выполнялась.

## Реализация и проверяемые требования

| Требование | Изменение | Проверка |
| --- | --- | --- |
| Один активный способ ввода | `input/mode.ts`, выбор coarse + maxTouchPoints, переключение с поглощением первого нажатия | Начальный touch, узкое окно desktop, клавиатура/мышь/касание, ввод в форме |
| Аналоговая ходьба | `input/touch.ts`, фиксированный стик, радиальная зона 12%, ограничение длины, общий `screenMovement`, sprint=false | Unit-тесты осей и нативные касания; движение подтверждено серверной позицией |
| Независимый поворот камеры | Отдельные pointerId и capture, горизонтальная чувствительность 0,005 рад/CSS-пиксель | Два пальца, третий палец, выход из зоны, оба порядка отпускания, смена ракурса |
| Сброс при прерывании | Общий сброс владельцев/capture/осей/сглаживания и нейтральный ввод сессии | touchcancel, потеря capture, resize, настоящий blur, WebGL, обрыв связи, пауза сохранения |
| Новые касания после восстановления | Гейт по готовности сессии/графики/страницы, старые pointerId забываются | Перемещение старых пальцев после восстановления не возобновляет движение |
| Ограничения действий | Доступность социальных панелей во всех обновлениях; явное отключение инвентаря и обработчиков | Авторизованный игрок, горячие клавиши, сетевые/периодические обновления, отмена предпросмотра |
| Служебные действия и экран | Сенсорные подсказки, safe-area, кнопки ≥44×44; отдельная активация валидного сенсорного отпускания | Вход, «На старт»/выход вторым пальцем при удерживаемом стике, повтор загрузки, обе ориентации телефона и планшета |
| Ограничение камеры | При touch масштаб 1, wheel отключён; desktop возвращает wheel | Переключение после изменения масштаба |
| Исправление DPR | hardwareScaling=1 / 1,5 независимо от DPR | DPR 1/2/3: 390×844 / 260×562; кадр мира одинаковый |

Нативные мультитач-события подаются через Chromium CDP, без вызова игровых обработчиков из JavaScript. Проверка обнаружила отсутствие совместимого `click` для кнопки под вторым пальцем; `ui/touch-buttons.ts` решает это и подавляет повторный совместимый click. Мышь и клавиатура используют обычные события кнопок. Отмена и уход пальца за кнопку не активируют действие.

Отдельно моделируется событие visibilitychange с временным изменением `document.hidden`. На этом стенде Chromium под Playwright оставлял фоновые страницы видимыми, включая оконный запуск под Xvfb. Это проверяет обработку жизненного цикла, но не подтверждает настоящее сворачивание мобильного браузера. Потеря фокуса проверена настоящей сменой вкладки. Пауза хранения вводится только в store изолированной фикстуры через путь ошибки подключения и штатное восстановление; production-сохранения не используются.

Внутреннее разрешение проверяется при DPR 1, 2 и 3. Эмуляция не измеряет производительность настоящего города на мобильном GPU. После проверок временные сервер и PostgreSQL остановлены; одноразовых схем в тестовой БД не осталось.

## Ручная мобильная приёмка

| Требуемое устройство | Результат |
| --- | --- |
| iPhone / Safari | Не проверено: реального устройства на стенде нет; модель/ОС/версия браузера не зафиксированы |
| Телефон Android / Chrome | Не проверено: реального устройства на стенде нет; модель/ОС/версия браузера не зафиксированы |
| Планшет / Safari или Chrome | Не проверено: реального устройства на стенде нет; модель/ОС/версия браузера не зафиксированы |

На каждом устройстве нужны обе ориентации и полный город: вход → несколько минут ходьбы с одновременным свайпом → остановка → сворачивание/возврат → «На старт» → выход. На гибридном устройстве — возврат к мыши/клавиатуре. Требуется записать качество и наблюдаемые проблемы, включая вырезы экрана и доступность кнопок.

Мобильная приёмка остаётся открытой. Увеличение числа пикселей при высоком DPR требует проверки производительности на реальном оборудовании; обещаний 30/60 FPS нет. Бег, изменение масштаба/наклона, сенсорные социальные панели и операции предметов остаются вне этого MVP.
